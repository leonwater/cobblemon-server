# 명령어 정리

- **모든 사용자**: OP 권한이 없어도 쓰는 명령어.
- **OP 전용**: 서버 콘솔이나 OP 권한(레벨 2 이상)이 있는 사용자만.
- OP 주기: 서버 콘솔에서 `op 닉네임` / 빼기: `deop 닉네임`.

## 모든 사용자

한국어·영어 어느 쪽으로 써도 같습니다. 닉네임 칸엔 **닉네임 또는 마인크래프트 아이디**.

| 한국어 | English | 하는 일 |
| --- | --- | --- |
| `G 키` · `/메뉴` | `/menu` | 메인 메뉴 (파티·PC·도감·워프·내 정보) |
| `/돈` | `/money` | 내 잔액 |
| `/송금 닉네임 금액` | `/pay 닉네임 금액` | 돈 보내기 |
| `/가기 닉네임` | `/tpa 닉네임` | 그 사람에게 이동 (**상대가 [예]**를 눌러야) |
| `/부르기 닉네임` | `/tpahere 닉네임` | 그 사람을 내 쪽으로 (**상대가 [예]**를 눌러야) |
| `/수락` · `/거절` | `/accept` · `/deny` | 받은 텔레포트 요청에 대답 (채팅의 [예]·[아니요]를 눌러도 됨) |
| `/광장` | `/spawn` | 광장으로 |
| `/명령어` | `/commands` | 명령어 목록 |
| `R 키` · `M 키` · `↑↓` | | 포켓몬 꺼내기 · 상태창 · 파티 고르기 (Cobblemon) |

### 텔레포트 규칙 (일반 사용자)
- 상대 채팅에 **[예] [아니요]**가 뜸. **10초** 안에 안 고르면 자동 취소.
- 못 쓰는 경우: 둘 중 한 명이 **튜토리얼 중**이거나 **체육관·사천왕 경기 중**.
- 한 사람에게 대답 안 한 요청이 있으면 새 요청은 잠시 뒤에.
- OP는 상대 동의 없이 **바로 이동**.

## OP 전용

### 돈·땅
| 명령어 | 하는 일 |
| --- | --- |
| `/pokeserver money give\|take\|set 닉네임 금액` | 돈 주기·빼기·정하기 |
| `/pokeserver deed 닉네임` | 농장 땅 문서 주기 |
| `/pokeserver unclaim 번호` | 농장 땅 주인 해제 |

### 화면·진행
| 명령어 | 하는 일 |
| --- | --- |
| `/pokeserver menu 닉네임` | 메인 메뉴 열어 주기 |
| `/pokeserver shop 닉네임` | 상점 열어 주기 |
| `/pokeserver tutorial 닉네임` | 오박사 튜토리얼 창 열어 주기 |
| `/초기화` → `/초기화 확인` (`/reset` → `/reset confirm`) | 내 모든 진행 삭제 후 튜토리얼부터 (확인 필요) |
| `/pokeserver reset 닉네임` | 그 사람 전체 초기화 |
| `/function poke:admin/reset_me` | 내 튜토리얼만 다시 (보상은 다시 안 줌) |

### 서버·월드
| 명령어 | 하는 일 |
| --- | --- |
| `/pokeserver legend` | 전설·환상 포켓몬 출현을 지금 한 번 (평소엔 1시간마다 자동) |
| `/pokeserver reload` | 농장·상점·메뉴 설정 다시 읽기 |
| `/pokeserver clearitems` | 바닥에 떨어진 아이템 지금 정리 (원래 10분마다 자동) |
| `/pokeserver npc skin 태그 스킨` | NPC 스킨 바꾸기 (`reset`이면 기본) |
| `/function poke:admin/rebuild` | 마을·NPC 다시 짓기 |
| `/tp`, `/gamemode`, `/give` 등 | 마인크래프트 기본 관리 명령 |
| `/whitelist on` · `/whitelist add 닉네임` | 아무나 못 들어오게 (친구만) |
| `/op 닉네임` · `/deop 닉네임` | OP 주기·빼기 |
| `/rctmod player get level_cap 닉네임` | 레벨 제한 확인 (체육관 모드) |
| `/pokegiveother 닉네임 포켓몬 level=N` | 포켓몬 주기 (Cobblemon) |
