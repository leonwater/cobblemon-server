# 야생 콘텐츠 (코블몬·Mega Showdown·전설 모드)

야생 맵(`poke:wild`)에서 만나는 것들과 그 보상. 근거는 모드 jar 안의 데이터(출현 설정·전리품 표·콜백)와 `pack/config/cobblemon/main.json`.
값은 Cobblemon 1.8.4, Mega Showdown 1.3.3, Complete Cobblemon Collection(전설 출현) 1.8.4 기준.

> **레이드(맥스 레이드·테라 레이드)는 없음.** 코블몬 1.8.4·Mega Showdown 1.3.3 어디에도 레이드 기능이 없음 (jar 안에 레이드 데이터·코드 없음). 다이맥스·테라스탈은 배틀 기믹으로만 있음.

## 1. 야생 포켓몬 출현
| 항목 | 값 | 비고 |
| --- | --- | --- |
| 어디서 | 야생 맵만 | 농장·튜토리얼·마을은 막음(`worldSpawningBlocklist`), 광장 둘레도 안 나옴 (`CobblemonHooks` 출현 이벤트) |
| 희귀도 칸 | common · uncommon · rare · ultra-rare · **boss** | 코블몬 기본 출현 설정 875개 + 무리 717개 |
| 이로치(색이 다른 포켓몬) | 1/8192 | `shinyRate` |
| 초보 구역 (첫 스폰 170칸 안) | 15레벨 이하, 종족값 합 300 이하, 아직 진화 못 했을 종은 안 나옴, 전설류 안 나옴 | 서버 규칙 |
| 마릿수 상한 | 야생에 있는 사람 1명당 정해진 수 | 렉 방지 (서버 규칙) |
| 경험치 | 기본의 2배 (`experienceMultiplier 2.0`), 학습장치 공유 0.5배 | 레벨 제한에 닿으면 안 오름 |

### 무리(herd)와 알파(Alpha)
- **무리**: 리더 1마리 + 같은 진화 줄 포켓몬 여러 마리가 함께 나옴 (최대 7마리 정도). 예: 이상해꽃 무리 = 리더 이상해꽃 + 이상해씨·이상해풀·이상해꽃.
- **알파**: 무리의 리더로 나오는 **크고 강한 포켓몬** (`alpha=true`, "boss" 칸, 레벨 30~100). 리더는 자기 타입 주얼을 지니고 나옴 (예: 이상해꽃 알파 = 풀주얼).
- **알파를 배틀로 쓰러뜨리면 보상** (`callbacks/battle_fainted/pokemon_alpha_drops.molang`, 그 자리에 떨어짐):

  | 알파 레벨 | 기본 보상 (1개) | 추가 |
  | --- | --- | --- |
  | 30 이하 | 경험사탕XS 1~3개 (62%) 또는 경험사탕S 1개 | 타입마다 50% 확률로 타입 보상 1단계: 그 타입 주얼 1~2개 (75%) 또는 반감 열매 (25%) |
  | 31~50 | 경험사탕S (53%) 또는 경험사탕M | 위와 같음 |
  | 51~65 | 경험사탕M (46%) 또는 경험사탕L | 타입 보상 2단계: 주얼 2~3개 또는 반감 열매 1~2개 |
  | 66 이상 | 경험사탕L·XL·이상한사탕 중 1개 + 90% 확률로 개체값 사탕(체력·공격·방어·특공·특방·스피드) 1개 | 위와 같음 |

- 알파는 화석 복원(5% = 1/20), 꿀 바르기(1/100)로도 나올 수 있음 (`fossilMachineAlphaChance`, `honeySlatherAlphaChance`).

### 전설·환상
- **1시간마다 자동 소환만 있음**: 야생(초보 구역 밖)에 있는 사람 중 한 명 근처에, 그 바이옴에 맞는 전설·환상 하나를 소환하고 전체 알림. 초보 구역엔 안 나옴.
- **자연 출현·낚시로는 안 나옴** (서버가 막음, `CobblemonHooks` 출현 이벤트). Complete Cobblemon Collection의 전설·환상 출현 설정은 자동 소환 때 "그 바이옴에 맞는 전설"을 고르는 데에만 씀.
- 울트라비스트·패러독스(같은 모드)는 지금도 아주 드물게 자연 출현 (초보 구역 제외).

## 2. 야생 배틀 보상
| 무엇 | 보상 | 근거 |
| --- | --- | --- |
| 야생 포켓몬 쓰러뜨림 | 경험치·노력치, 종마다 정해진 떨어뜨리는 물건 (예: 깨비참 → 날개) | 코블몬 종 데이터 `drops` |
| 야생 포켓몬 쓰러뜨림 | **5% 확률로 그 포켓몬 첫 번째 타입의 Z크리스탈** | 서버 규칙 (`Z_DROP`) |
| 알파 쓰러뜨림 | 위 표 | 코블몬 콜백 |
| 돈 | **없음** (야생 배틀은 돈을 안 줌) | 돈은 체육관·판매로 |
| 야생 트레이너 | **꺼져 있음** (RCT `globalSpawnChance = 0.0`) | 트레이너는 체육관·사천왕만 |

## 3. 낚시
- **포켓몬 낚싯대**(상점 볼 분류 500원)로만 포켓몬이 낚임. 일반 낚싯대는 물고기·물건만 (실제 게임에서 갸라도스·잉어킹·발챙이 낚아 확인).
- 낚시도 야생 출현 규칙을 그대로 따름 (농장·광장 근처는 안 걸림, 초보 구역은 약한 포켓몬만).
- 미끼: 낚싯대에 열매 등을 달면 나오는 포켓몬·성격·이로치 확률 등이 바뀜 (코블몬 `SpawnBait`).
- 볼 모양 낚싯대: 대장장이 형판(상점 2,000원, 낚싯배·난파선에서도 나옴) + 낚싯대 + 볼.

## 4. 야생 구조물과 보상
야생 맵은 오버월드와 같은 지형·바이옴이라 아래 구조물이 바이옴 조건에 맞으면 생김.
실제 서버(1.5.0, 배포 방식)에서 `locate structure`로 확인: 원점 기준 메가로이드 355칸, 메가 사이트 272칸, 낚싯배 537칸, 서식지(열매 밭) 837칸, 소원의 숲 1,380칸, 천문대 1,923칸, 고고학 유적 2,542칸, 유적(고대 제단) 8,735칸, 난파선 동굴 10,115칸. 메가 구조물·낚싯배·서식지는 가깝고 흔하며, 코블몬 유적·난파선 동굴은 수천 칸 이상 멀어 드묾.

### 코블몬
| 구조물 | 어디 | 안에 있는 것 |
| --- | --- | --- |
| **유적**(ruins) 29종: 고대 제단·무너진 아치·지하 묘지·별 들판(henge) 등 | 바이옴별 | 일반 상자: 유물 동전(48%)·구리·철·주얼 / 덜 흔한 상자: 클리어참·저주의부적·도자기 조각 / 드문: 텀블스톤, 갑옷 장식 형판 |
| 유적의 **금빛 상자**(gilded chest, 유적마다 1개) | 유적 안 | 고대 지닌 도구·진화의 돌·경험사탕·주얼·회복 열매 중 몇 개 + **이상한사탕 1~3개** + 유물 동전 10~20개 ×2~3 + **그 유적 기술머신 1장** (예: 알루어링보이스·드래곤애로우…) |
| **김홀(gimmi) 탑** 6종 | 사막·눈·숲 등 | 유물 동전 → 모아서 김홀 진화에 씀 |
| **난파선 동굴**(shipwreck cove) 3종 | 바다·해안 | 큰 보물: 바다의 심장·다이아 1~4·에메랄드/금 3~12·신비의물방울·깊은바다의이빨/비늘·용의비늘 등 + **포켓몬 낚싯대 형판 2~3장** + 기술머신 / 작은 보물: 물의돌·유물 동전·다이브·네트·루어볼 3~5개·주얼 |
| **낚싯배** | 해안·바다 | 지도·**낚싯대 형판**·낚싯대·생선·유물 동전·네트·다이브·루어볼 |
| **서식지**(habitats) 29종: 열매 밭·연못·꽃밭·화산 틈 등 | 바이옴별 | 상자 없음. 열매 나무·꽃 등 꾸밈 + 그 환경에 맞는 포켓몬이 잘 나옴 |
| 자연물: 규토리 나무(`baseApricornTreeGenerationChance 0.1`), 민트, 부활초, 텀블스톤 | 바이옴별 | 볼 재료·성격 민트·회복 |

### Mega Showdown
| 구조물 | 어디 | 안에 있는 것 |
| --- | --- | --- |
| **메가 사이트**(mega_site) | 오버월드 바이옴 어디나 | 메가스톤 결정 블록 → 캐면 메가스톤 원석 |
| **메가로이드**(megaroid, 운석) | 오버월드 어디나 | 메가 운석 광석들 → 캐면 불꽃·물·천둥·리프·얼음·달·해·빛·어둠의돌 등 진화의 돌, 키스톤 광석 → **무작위 메가스톤 1개** (서버가 바꿈: 원래는 키스톤) |
| **고고학 유적**(archaeological_site) | 사막 | 수상한 모래 붓질: 빛나는 돌(빛·어둠) 등, 다크주얼·다이아·경험사탕L·메가 운석 블록 |
| **천문대**(observatory) | 정글 | 꼭대기 상자: **고대 윙볼** + 진화의 돌·주얼·망원경·자수정 |
| **소원의 숲**(wishing_weald) | 으스스한 숲 | 상자: **지가르데 셀 1~2개** + 고대 지닌 도구·진화의 돌·경험사탕·배틀 도구 / 소원의 별 결정 → **무작위 메가스톤 1개** (서버가 바꿈: 원래는 소원의 별) |
| 다이버섯(max mushroom) | 자연 생성 | 거다이맥스용 다이버섯 (상점에서도 팜) |

> **플레이어가 끼는 기믹 도구(Z링·메가링·다이맥스밴드·테라스탈 오브·옴니링)는 야생에서 못 얻고 만들 수도 없음.** 체육관 보상으로만 받음.
> 키스톤·소원의 별이 나오던 결정은 메가스톤을 주고, 그 도구들의 제작법 35개는 꺼 둠 (데이터팩 `data/mega_showdown/recipe`, `loot_table/blocks`). 포켓몬에게 지니게 하는 메가스톤·Z크리스탈·다이버섯은 그대로 얻을 수 있음.

## 5. 화석
- 유적·고고학에서 화석을 얻어 **화석 분석기 + 복원 탱크**로 고대 포켓몬을 되살림 (코블몬). 복원된 포켓몬은 5% 알파, 1% 이로치.

## 6. 서버가 바꾼 것 (요약)
- 야생에서 얻는 귀중품(메가스톤·Z크리스탈·다이버섯·진화의 돌)은 상점에 팔 때 구매가의 1/20 (예: 메가스톤 1,500원, 전설 메가스톤 2,500원, Z크리스탈 500~750원, 진화의 돌 150원).
- 야생 트레이너 끔, 광장 둘레·농장 출현 끔, 초보 구역 제한, 마릿수 상한, 전설·환상은 1시간 자동 소환만, 플레이어 기믹 도구 야생 획득·제작 막음(키스톤·소원의 별 → 메가스톤), Z크리스탈 5%, 경험치 2배, 레벨 제한.
- 다이맥스: Mega Showdown은 원래 **파워 스팟 블록 근처에서만** 다이맥스가 되지만, 서버에서는 체육관·사천왕·플레이어 배틀에선 어디서나 됨 (`DynamaxSpotMixin`). 야생 배틀은 원래대로 파워 스팟 근처에서만.
