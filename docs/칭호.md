# 칭호 (지금 18개 → 새 안 40개)

게임 화면(G 메뉴 → 칭호)에는 **힌트만** 보이고 정확한 조건 수치는 안 보임 (2.1.0부터). 정확한 조건은 이 문서와 코드(`Titles.java`)에만.
칭호는 조건을 채우면 자동으로 얻고, 안 고르면 우선순위가 가장 높은 것이 `[칭호] 닉네임`으로 붙음. ★ = 얻으면 서버 전체 공지.

> **아래는 검토용 새 안입니다 (아직 게임에 없음).** 지금 게임엔 2.1.0 이름·힌트가 그대로 있고, 확정되면 다음 버전에 한꺼번에 넣습니다.
> 바뀌는 점: 이름을 새로 짓고, 힌트는 명사로 끝내고("~하면" → "~한 트레이너"), **1억 관련 칭호(재벌·억만장자)는 뺌**.

## 4. 넣을 때 할 일 (확정되면 다음 버전)
- `Titles.ALL`: 이름·힌트 바꾸기, `tycoon`(재벌) 줄 삭제 (이미 고른 사람은 다음으로 높은 칭호가 자동으로 붙음), 새 줄 23개 추가.
- **새로** 표시 칭호: 해당 이벤트에서 `Titles.add(p, "키", 1)` — 포획(이로치·낚시), 배틀 승리(야생·알파·연승·무손실), 기믹 사용, 화석 복원, 작물 수확, 야생 이동 거리, 접속 날짜, 퍼스트 클리어·사천왕 첫 도전.
- 칭호 고르기 창: 3칸씩 줄이 늘어남 (18개 → 40개) → 스크롤 필요.
