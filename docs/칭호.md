# 칭호 (38개, 2.4.0부터 게임에 들어감, 2.5.0 개근상·2.6.0 목장 주인 삭제)

게임 화면(G 메뉴 → 메뉴 → 칭호)에는 **이름과 힌트만** 보이고 (마우스를 올리면 힌트 문장만, "힌트:" 글자 없이), 정확한 조건 수치는 안 보임. 정확한 조건은 이 문서와 코드(`Titles.java`)에만 있음.
조건을 채우면 칭호를 자동으로 얻음. 직접 안 고르면 **우선순위**가 가장 높은 칭호가 `[칭호] 닉네임`으로 붙음. ★ = 얻으면 서버 전체에 공지.

- **이름:** 포켓몬 게임 속 직함·장소·도구 이름에서 따옴. 같은 갈래는 아래 → 위로 이어지는 사다리.
- **힌트:** 모두 명사로 끝남. 1억 관련 칭호(재벌)는 2.4.0에서 삭제함. 이미 재벌을 골랐던 사람에게는 다음으로 높은 칭호가 붙음.
- **고르기 창:** 5칸씩이고, **같은 갈래는 같은 줄에서 시작**. 순서는 아래 표 그대로(갈래 안에서는 쉬운 것 → 어려운 것). 긴 이름은 최대 0.8배까지 글자를 줄여 다 보이게 함.
- **주의:** '참고' 칸의 한국어 이름은 공식 한국어판 자료와 대조하지 못함 (검색에서는 영어·일본어 자료만 나옴).
  - 테라 레이드 마스터·포켓몬 워처·퍼펙트·오랜 파트너는 게임 속 이름이 아님. 게임 용어를 빌려 지은 이름.

## 기록 방식 메모
- 숫자 기록은 `ServerData.stats`(플레이어별)에 저장됨. 세는 곳은 `CobblemonHooks.titleEvents()`, `Titles.track()`(1초마다), `PokeServer`(작물 부수기).
- 2.4.0 전에는 세지 않던 기록은 0부터 시작함: 이로치·낚시·화석·야생/알파 쓰러뜨림·기믹 횟수·연승·수확·이동 거리·퍼펙트·무적의 챔피언.
  - 배지·도감·돈·땅·플레이 시간·레벨 100은 지금 상태로 바로 계산됨.
- 사천왕 첫 도전 기록은 2.4.0부터 셈. 그전에 사천왕에 도전한 적이 있어도 2.4.0 뒤 첫 도전에 클리어하면 무적의 챔피언을 얻음.
- `/초기화`(admin/wipe_me)는 새 태그(`poke.e4tried`·`poke.e4retry`·`poke.e4first`·`poke.firstclear`)도 지움.
