# 운영자 명령어

서버 콘솔이나 OP 권한(레벨 2 이상)이 있는 사용자만. OP 주기: 서버 콘솔에서 `op 닉네임` / 빼기: `deop 닉네임`. OP는 텔레포트 요청 없이 바로 이동.

### 돈·땅
| 명령어 | 하는 일 |
| --- | --- |
| `/pokeserver money give\|take\|set 닉네임 금액` | 돈 주기·빼기·정하기 |
| `/pokeserver deed 닉네임` | 농장 땅 문서 주기 |
| `/pokeserver unclaim 번호` | 농장 땅 주인 해제 |

### 화면·진행
| 명령어 | 하는 일 |
| --- | --- |
| `/pokeserver menu 닉네임` | 메인 메뉴 열어 주기 |
| `/pokeserver shop 닉네임` | 상점 열어 주기 |
| `/pokeserver tutorial 닉네임` | 오박사 튜토리얼 창 열어 주기 |
| `/초기화` (`/reset`) | **서버 전체 초기화: 맵까지 새로**. 모두 내보내고 서버를 끔 → 다음 시작 때 새 월드 (`start.bat`이 바로 다시 켬). 이전 월드는 서버 폴더 `world-backup-...`에 보관 (배틀 기록 `battle_logs`도 같이). 새 월드를 다 지은 뒤 서버를 열기 전에 바닥에 떨어진 아이템을 한 번 정리. **초기화 안 되는 것**: 운영자 목록(운영자 칭호·권한), 화이트리스트, 차단 목록 |
| `/초기화 닉네임` (`/reset 닉네임`) | 그 사람만 초기화 (접속 중인 사람): 아이템·돈·땅·포켓몬·도감·배지·칭호 기록 → 바로 튜토리얼 방으로, 다시 끝내면 기본 물품(5,000원 등) 다시 받음 |
| `/pokeserver reset 닉네임` | 그 사람 전체 초기화 |
| `/function poke:admin/reset_me` | 테스트용: 내 튜토리얼만 다시 (보상은 다시 안 줌) |

### 서버·월드
| 명령어 | 하는 일 |
| --- | --- |
| `/pokeserver legend` | 전설·환상 포켓몬 출현을 지금 한 번. **처음 치면 그때부터 1시간마다 자동 출현이 켜짐** (그전엔 전설이 안 나옴, 서버를 다시 켜도 기억) |
| `/pokeserver legend stop` | 1시간마다 자동 출현 끄기 |
| `/pokeserver reload` | 농장·상점·메뉴 설정 다시 읽기 |
| `/공지 내용` · `/announce 내용` | 서버 전체 채팅에 **[공지] 내용** (운영자만) |
| `/pokeserver clearitems` | 바닥에 떨어진 아이템 지금 정리 (원래 10분마다 자동) |
| `/pokeserver npc skin 태그 스킨` | NPC 스킨 바꾸기 (`reset`이면 기본) |
| `/function poke:admin/rebuild` | 마을·NPC 다시 짓기 |
| `/강제가기 닉네임` · `/ftp 닉네임` | 상대 수락 없이 바로 그 사람에게 이동 (운영자만) |
| `/강제부르기 닉네임` · `/ftpa 닉네임` | 상대 수락 없이 바로 내 옆으로 데려옴 (운영자만) |
| `/tp`, `/gamemode`, `/give` 등 | 마인크래프트 기본 관리 명령 (운영자의 `/tp`는 원래 마크 명령, 일반 유저의 `/tp 닉네임`은 요청제 `/가기`) |
| `/whitelist on` · `/whitelist add 닉네임` | 아무나 못 들어오게 (친구만) |
| `/op 닉네임` · `/deop 닉네임` | OP 주기·빼기 |
| `/rctmod player get level_cap 닉네임` | 레벨 제한 확인 (체육관 모드) |
| `/pokegiveother 닉네임 포켓몬 level=N` | 포켓몬 주기 (Cobblemon) |

### 코블몬 명령어 (다른 플레이어에게 영향을 주는 것만)
`슬롯` = 파티 칸 번호(1~6), `속성` = 코블몬 속성 글 (예: `pikachu level=20 shiny=yes`). 서버 사용법은 `help 명령어`로 확인.

| 명령어 | 하는 일 |
| --- | --- |
| `/pokegiveother 닉네임 속성` (`/givepokemonother`) | 포켓몬 주기 (파티가 차면 PC로) |
| `/pokeheal [닉네임]` (`/healpokemon`) | 파티 포켓몬 모두 회복 |
| `/levelup 닉네임 슬롯` | 그 포켓몬 1레벨 올리기 |
| `/pokemoneditother 닉네임 슬롯 속성` | 포켓몬 속성 바꾸기 (레벨·이로치·성격·특성 등) |
| `/teach 닉네임 슬롯 기술` | 기술 가르치기 |
| `/held_item 닉네임 슬롯 아이템` | 지닌 물건 바꾸기 |
| `/givemark 닉네임 슬롯 증표` · `/takemark …` | 증표 주기·빼기 |
| `/takepokemon 닉네임 슬롯` | 파티 포켓몬 빼앗기 (되돌릴 수 없음) |
| `/clearparty 닉네임` · `/clearpc 닉네임` | 파티·PC 전부 지우기 (되돌릴 수 없음) |
| `/pokebox 닉네임 슬롯 [박스]` | 파티 포켓몬을 PC로 보내기 |
| `/pctake 닉네임 박스 슬롯` | PC 포켓몬 빼앗기 |
| `/pcsearch other 닉네임 속성` | 다른 사람 PC에서 찾기 |
| `/boxcount query\|add\|remove\|set 닉네임 [수]` | PC 박스 수 확인·바꾸기 |
| `/unlockpcboxwallpaper 닉네임 배경` | PC 배경 열어 주기 |
| `/pokedex grant\|revoke 닉네임 all\|only` | 도감 채우기·지우기 |
| `/technicalmachine unlock\|lock\|check 닉네임 …` | 기술머신 기록 열기·잠그기 |
| `/givetm 기술 [수\|닉네임]` | 기술머신 주기 |
| `/stopbattle 닉네임` | 그 사람 배틀 강제 종료 |
| `/pokemonrestartother 닉네임 [스타팅초기화]` | 그 사람 코블몬 진행 처음부터 (포켓몬 모두 지움) |
| `/openstarterscreen 닉네임` | 스타팅 포켓몬 고르기 창 열기 |
| `/spawnpokemonat 위치 속성` · `/pokespawn 속성` | 포켓몬 소환 (전설 포함) |
