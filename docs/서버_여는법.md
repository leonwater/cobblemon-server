# 서버 여는 법 · 플레이 방법

자세한 표·문제 해결은 README에 있습니다. 여기는 순서만 짧게.

## 1. 서버 열기 (Windows, 한 번만 준비)

1. `C:\pokeserver` 폴더를 만든다 (한글·공백 없는 경로).
2. 파일 4개를 넣는다.
   - Java 21 **zip** (adoptium.net, `.msi` 말고 `.zip`) → 압축 풀어 폴더째.
   - Fabric 서버 jar (fabricmc.net/use/server, MC **1.21.1**, Loader **0.20.1**).
   - `packwiz-installer-bootstrap.jar` (GitHub packwiz-installer-bootstrap 최신 릴리스).
   - `start.bat`, `update.bat` (이 저장소 `server/` 폴더).
3. `start.bat` 더블클릭 → EULA 안내에서 멈춤 (정상).
4. `eula.txt`를 열어 `eula=true`로 저장.
5. `start.bat` 다시 실행 → `Done (...)!`이 나오면 켜짐.
6. 방화벽 창은 **취소** (혼자 할 땐 필요 없음).
7. 서버 창에 `op 내아이디` → 운영자 권한 (별명 `[운영자]`가 붙음).
8. 끌 때는 서버 창에 `stop` (X로 닫지 않기).

수정사항 반영: 데이터팩은 `update.bat` → 서버 창 `reload`. 모드는 `stop` → `start.bat`.

## 2. 혼자 플레이 (로컬호스트)

내 PC 한 대로 서버(1번)를 켜고, 같은 PC에서 게임으로 들어갑니다. 정품 마인크래프트(Microsoft 계정)가 필요합니다.

### 2-1. 런처 설치 (처음 한 번)
1. **Prism Launcher** 받기: https://prismlauncher.org/download/windows/
   - **Installer**(설치 파일, `PrismLauncher-Windows-...-Setup.exe`)를 받아 실행 → 계속 "다음" → 설치.
2. Prism Launcher 실행 → 처음 설정 창:
   - 언어: **한국어** 선택 → 다음.
   - Java: 그대로 두고 다음 (필요하면 나중에 자동으로 받음).
3. 오른쪽 위 **계정(Accounts) → 계정 관리 → Microsoft 추가**.
   - 브라우저가 열리면 마인크래프트를 산 Microsoft 계정으로 로그인 → 런처로 돌아오면 끝.

### 2-2. 인스턴스(게임 하나) 만들기
1. 왼쪽 위 **인스턴스 추가(Add Instance)**.
2. 이름: `포켓서버`.
3. 왼쪽 **사용자 지정(Custom)** → 버전 목록에서 **1.21.1** 선택.
4. 아래 **모드 로더(Mod loader)**: **Fabric** 선택 → 버전 **0.20.1** 선택 → **확인**.
5. 만든 인스턴스 **오른쪽 클릭 → 편집(Edit) → 설정(Settings) → Java** 탭:
   - **메모리(Memory)** 체크 → 최대 메모리 **6144 MB** (PC 메모리가 8GB면 4096).
   - 창 닫기 (자동 저장).

### 2-3. `minecraft` 폴더 찾기
1. 인스턴스를 **한 번 실행 → 타이틀 화면이 뜨면 끄기** (이때 폴더가 생김).
   - "Java를 받을까요?" 같은 창이 뜨면 **예/다운로드**.
2. 인스턴스 **오른쪽 클릭 → 폴더(Folder)** → 탐색기가 열림.
3. 열린 곳에 `instance.cfg`와 **`minecraft`** 폴더가 보임 → **`minecraft` 안으로 들어가기**.
   - 들어가면 `mods`, `saves`, `options.txt` 같은 것이 보이는 곳이 맞는 곳.
   - 주소로 바로 가기: `Win + R` → `%APPDATA%\PrismLauncher\instances\포켓서버\minecraft` → 확인.
   - `minecraft` 대신 `.minecraft`인 경우도 있음 (같은 것).

### 2-4. 모드 자동 설치 파일 넣기
1. `packwiz-installer-bootstrap.jar` 받기 (1번에서 받은 것과 같은 파일):
   https://github.com/packwiz/packwiz-installer-bootstrap/releases/latest/download/packwiz-installer-bootstrap.jar
2. 그 파일을 **2-3의 `minecraft` 폴더 안**에 넣기.
   - 이름이 정확히 `packwiz-installer-bootstrap.jar`인지 확인 (`(1)`이 붙었으면 지우기).
3. 인스턴스 **오른쪽 클릭 → 편집 → 설정 → 사용자 지정 명령(Custom commands)** 탭:
   - **사용자 지정 명령** 체크.
   - **실행 전 명령(Pre-launch command)** 칸에 아래 한 줄을 그대로 붙여넣기:
   ```
   "$INST_JAVA" -jar "$INST_MC_DIR/packwiz-installer-bootstrap.jar" --bootstrap-main-jar "$INST_MC_DIR/packwiz-installer.jar" https://raw.githubusercontent.com/leonwater/cobblemon-server/main/pack/pack.toml
   ```
   - 창 닫기 (자동 저장).

### 2-5. 실행·접속
1. 인스턴스 **더블클릭** → 작은 다운로드 창이 뜸 (처음엔 모드를 받느라 몇 분) → 게임이 켜짐.
   - 타이틀 화면 **모드(Mods)** 목록에 **Cobblemon**이 있으면 성공.
   - 다음부터는 실행할 때마다 서버와 같은 모드로 자동으로 맞춰짐.
2. **서버를 먼저 켜 둠** (1번의 `start.bat`, `Done (...)!`이 나온 상태).
3. **멀티플레이 → 서버 추가** → 서버 주소 **`localhost`** → 완료 → 더블클릭으로 접속.

### 막힐 때
- `Unable to access jarfile`: 2-4의 파일이 `minecraft` 폴더 **안**에 없거나 이름이 다름. 탐색기 **보기 → 파일 확장명** 켜고 `.jar.jar`인지 확인.
- 게임이 느리거나 꺼짐: 2-2의 메모리를 4096~6144로. 셰이더는 **K 키**로 끄기.
- 접속이 안 됨: 서버 창에 `Done`이 나왔는지, 주소가 `localhost`인지 확인.
- 더 자세한 표: README "클라이언트 → 막힐 때".

## 3. 친구와 멀티 플레이 (playit.gg)

공유기 설정·집 IP 공개 없이 터널로 들어옵니다.

**서버 PC (한 번만)**
1. playit.gg 가입 → Windows용 프로그램 설치·실행·로그인.
2. **Tunnels → Add Tunnel** → Minecraft Java, Local `127.0.0.1:25565`.
3. 받은 주소(예: `xxxx.joinmc.link`)를 친구에게 알려 준다.
4. 서버 창에서 화이트리스트:
   ```
   whitelist on
   whitelist add 내아이디
   whitelist add 친구아이디
   ```
5. 서버를 켤 때 playit 프로그램도 켜 둔다.

**친구 PC**
1. 위 "2. 혼자 플레이"의 2-1 ~ 2-5의 1번까지 똑같이.
2. 멀티플레이 → 서버 추가 → 주소에 **playit 주소**.
3. 정품 계정이어야 접속됨.

## 4. 처음 접속하면

1. 오박사 연구소에서 **오박사 우클릭** → 튜토리얼 11쪽.
2. 마지막 쪽에서 **닉네임**을 적고 **준비 완료!**
3. 스타팅 포켓몬 고르기.
4. 연구소 **뒤의 철문**으로 나가면 광장.
5. **G 키**: 메인 메뉴. 명령어 목록: `/명령어` (`/commands`).
