# 서버 여는 법 (서버장용)

자세한 표·문제 해결은 README에 있습니다. 여기는 순서만 짧게.

## 1. 서버 열기 (Windows, 한 번만 준비)

1. `C:\pokeserver` 폴더 (폴더 이름은 영문이면 아무거나)를 만든다 (한글·공백 없는 경로).
2. 파일 4개를 넣는다.
   - Java 21 **zip** (adoptium.net, `.msi` 말고 `.zip`) → 압축 풀어 폴더째.
   - Fabric 서버 jar (fabricmc.net/use/server, MC **1.21.1**, Loader **0.20.1**).
   - `packwiz-installer-bootstrap.jar` (GitHub packwiz-installer-bootstrap 최신 릴리스).
   - `start.bat`, `update.bat` (이 저장소 `server/` 폴더).
3. `start.bat` 더블클릭 → EULA 안내에서 멈춤 (정상).
4. `eula.txt`를 열어 `eula=true`로 저장.
5. `start.bat` 다시 실행 → `Done (...)!`이 나오면 켜짐.
6. 방화벽 창은 **취소** (혼자 할 땐 필요 없음).
7. 서버 창에 `op 내아이디` → 운영자 권한 (칭호 `[운영자]`가 붙음).
8. 끌 때는 서버 창에 `stop` (X로 닫지 않기).

**업데이트 반영 (가장 간단한 방법)**: 서버 창에 `stop` → 꺼지면 `start.bat` 다시 실행. `start.bat`이 켜기 전에 GitHub에서 최신 모드·데이터팩을 자동으로 받습니다.
- 친구(접속하는 사람)는 게임을 껐다 켜면 됨 (실행 전 명령이 최신 모드를 받음).
- `start.bat`/`update.bat` 파일 자체가 바뀐 경우만 1-1처럼 다시 내려받기 (전체 초기화 후 자동 재시작은 새 `start.bat`이 필요).
- 데이터팩만 바뀐 경우 끄지 않고 `update.bat` → 서버 창 `reload`도 됨. 헷갈리면 그냥 `stop` → `start.bat`.

## 2. 서버장 본인 접속 (로컬호스트)

게임 준비(런처 설치·인스턴스·모드 자동 설치)는 서버원과 같습니다 → **접속 방법** 문서 1~4번.

### 접속
1. **서버를 먼저 켜 둠** (1번의 `start.bat`, `Done (...)!`이 나온 상태).
2. **멀티플레이 → 서버 추가** → 서버 주소 **`localhost`** → 완료 → 더블클릭으로 접속.
3. 접속이 안 되면: 서버 창에 `Done`이 나왔는지, 주소가 `localhost`인지 확인. 더 자세한 표는 README "클라이언트 → 막힐 때".

## 3. 친구와 멀티 플레이 (playit.gg)

공유기 설정·집 IP 공개 없이 playit.gg 터널로 들어옵니다. 서버는 여전히 **서버장 PC에서** 돌아가므로, 서버장 PC·서버 창·playit 프로그램이 모두 켜져 있어야 접속됩니다.

### 주소 두 개 구분
| 주소 | 누가 쓰나 | 어디에 |
| --- | --- | --- |
| `127.0.0.1:25565` | playit 프로그램 | 터널 만들 때 **Local Address/Port**에 넣는 값. 접속 주소 아님 |
| `xxxx.joinmc.link` (또는 `xxx.ply.gg:12345`) | **친구** | 멀티플레이 → 서버 추가 → 서버 주소 |
| `localhost` | **서버장 본인** | 같은 PC에서 접속할 때 (playit 주소로도 됨) |

- 터널을 만들면 playit 웹 화면의 터널 목록에 **도메인 주소**가 보입니다. 이게 친구가 넣는 주소입니다.
- 주소 뒤에 `:숫자`(포트)가 붙어 있으면 **숫자까지 그대로** 넣습니다. `joinmc.link`처럼 숫자가 없으면 도메인만 넣으면 됩니다.

### 서버장 PC (한 번만)
1. playit.gg 가입 → **Download** → Windows용 설치 → 실행해서 로그인 (프로그램과 계정 연결).
2. playit 웹 화면 **Tunnels → Add Tunnel** → 종류 **Minecraft Java**, Local Address `127.0.0.1`, Local Port `25565`.
3. 터널 목록에 나온 **도메인 주소**를 친구에게 알려 준다.
4. (선택) **화이트리스트**: 기본은 꺼져 있어 **주소만 알면 누구나** 들어옵니다. 아는 사람만 들어오게 하려면 친구에게 **마인크래프트 아이디**(정품 계정 이름, 게임 안 닉네임 아님)를 받아 켭니다.
   - **서버 창**(`start.bat`을 켜면 나오는 검은 창)의 맨 아래에 한 줄씩 입력하고 Enter. 서버 창에선 `/` 없이 씀.
   - 처음 한 번만 화이트리스트 켜기:
     ```
     whitelist on
     ```
   - 나와 친구를 한 명씩 추가 (아이디는 대소문자까지 정확히):
     ```
     whitelist add 내마인크래프트아이디
     ```
     ```
     whitelist add 친구마인크래프트아이디
     ```
   - 잘 들어갔는지 보기: `whitelist list` · 빼기: `whitelist remove 아이디`
   - 게임 안에서 할 때는 운영자(OP)가 채팅에 `/whitelist add 아이디` (앞에 `/`).
   - 저장되므로 서버를 다시 켜도 유지됨.
5. 이후 서버를 켤 때마다: `start.bat` + playit 프로그램 둘 다 켜 두기.
6. 서버 설정(`server.properties`의 `server-ip=127.0.0.1`)은 **바꾸지 않는다**. playit이 같은 PC 안에서 서버에 붙기 때문.

### 서버원에게 줄 것
- **접속 방법** 문서 (잡켓몬 서버 문서)와 서버 주소(playit 도메인)만 주면 됩니다. 화이트리스트를 켰다면 서버원의 마인크래프트 아이디도 받아서 추가.

### 접속이 안 될 때
- "화이트리스트에 없습니다": 화이트리스트를 켰다면 `whitelist add 아이디`를 했는지 (아이디 철자 확인).
- 연결 시간 초과: 서버장 PC에서 서버 창(`Done`)과 playit 프로그램이 둘 다 켜져 있는지, 터널 Local Port가 `25565`인지.
- "모드가 맞지 않습니다"/접속 직후 튕김: 친구가 실행 전 명령을 넣었는지, 게임을 한 번 껐다 켜서 모드가 업데이트됐는지.

### 몇 명까지 들어올 수 있나 (추정)
- 정확한 최대 인원은 PC 성능에 따라 달라 **직접 재 봐야 함**. 아래는 호스팅 업체들의 Cobblemon 권장값을 바탕으로 한 추정.
- 지금 `start.bat`은 서버 메모리 **4GB**(`-Xmx4G`): **권장 2~4명, 5명쯤부터 렉 가능성**. 서버장도 같은 PC로 게임을 하면 더 적게.
- PC 메모리가 16GB 이상이면 `start.bat`의 `-Xmx4G`를 `-Xmx6G`~`-Xmx8G`로 올리면 **6~10명**까지 기대 (게임 클라이언트 메모리도 남겨야 함).
- playit.gg 무료 요금제는 공식 인원 제한은 안 보이나, 대역폭 제한이 있어 **친구 몇 명 규모**에 맞음. 핑이 10~50ms 정도 늘 수 있음.
- `server.properties`의 `max-players`(기본 20)가 입장 상한.
