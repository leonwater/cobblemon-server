# 서버 여는 법 · 플레이 방법

자세한 표·문제 해결은 README에 있습니다. 여기는 순서만 짧게.

## 1. 서버 열기 (Windows, 한 번만 준비)

1. `C:\pokeserver` 폴더를 만든다 (한글·공백 없는 경로).
2. 파일 4개를 넣는다.
   - Java 21 **zip** (adoptium.net, `.msi` 말고 `.zip`) → 압축 풀어 폴더째.
   - Fabric 서버 jar (fabricmc.net/use/server, MC **1.21.1**, Loader **0.20.1**).
   - `packwiz-installer-bootstrap.jar` (GitHub packwiz-installer-bootstrap 최신 릴리스).
   - `start.bat`, `update.bat` (이 저장소 `server/` 폴더).
3. `start.bat` 더블클릭 → EULA 안내에서 멈춤 (정상).
4. `eula.txt`를 열어 `eula=true`로 저장.
5. `start.bat` 다시 실행 → `Done (...)!`이 나오면 켜짐.
6. 방화벽 창은 **취소** (혼자 할 땐 필요 없음).
7. 서버 창에 `op 내아이디` → 운영자 권한 (별명 `[운영자]`가 붙음).
8. 끌 때는 서버 창에 `stop` (X로 닫지 않기).

수정사항 반영: 데이터팩은 `update.bat` → 서버 창 `reload`. 모드는 `stop` → `start.bat`.

## 2. 혼자 플레이 (로컬호스트)

1. Prism Launcher에서 **Minecraft 1.21.1 + Fabric** 인스턴스를 만든다.
2. `packwiz-installer-bootstrap.jar`를 인스턴스의 `minecraft` 폴더에 넣는다.
3. 인스턴스 **Edit → Settings → Custom commands → Pre-launch command**에 붙여넣기:
   ```
   "$INST_JAVA" -jar "$INST_MC_DIR/packwiz-installer-bootstrap.jar" --bootstrap-main-jar "$INST_MC_DIR/packwiz-installer.jar" https://raw.githubusercontent.com/leonwater/cobblemon-server/main/pack/pack.toml
   ```
4. Microsoft 계정으로 로그인 → 인스턴스 실행 (모드가 자동으로 맞춰짐).
5. 서버를 켠 채로 **멀티플레이 → 서버 추가 → 주소 `localhost`**.

## 3. 친구와 멀티 플레이 (playit.gg)

공유기 설정·집 IP 공개 없이 터널로 들어옵니다.

**서버 PC (한 번만)**
1. playit.gg 가입 → Windows용 프로그램 설치·실행·로그인.
2. **Tunnels → Add Tunnel** → Minecraft Java, Local `127.0.0.1:25565`.
3. 받은 주소(예: `xxxx.joinmc.link`)를 친구에게 알려 준다.
4. 서버 창에서 화이트리스트:
   ```
   whitelist on
   whitelist add 내아이디
   whitelist add 친구아이디
   ```
5. 서버를 켤 때 playit 프로그램도 켜 둔다.

**친구 PC**
1. 위 "2. 혼자 플레이"의 1~4번을 똑같이.
2. 멀티플레이 → 서버 추가 → 주소에 **playit 주소**.
3. 정품 계정이어야 접속됨.

## 4. 처음 접속하면

1. 오박사 연구소에서 **오박사 우클릭** → 튜토리얼 11쪽.
2. 마지막 쪽에서 **닉네임**을 적고 **준비 완료!**
3. 스타팅 포켓몬 고르기.
4. 연구소 **뒤의 철문**으로 나가면 광장.
5. **G 키**: 메인 메뉴. 명령어 목록: `/명령어` (`/commands`).
