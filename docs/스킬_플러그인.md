# 사용할 수 있는 스킬·플러그인

이 작업 환경(Claude Code 클라우드)에서 쓸 수 있는 것들. `/이름`으로 부르거나, 작업에 맞으면 Claude가 직접 씀.

## 이 서버 작업에 자주 쓰는 것
| 이름 | 하는 일 | 이 프로젝트에서 |
| --- | --- | --- |
| `ui-ux-pro-max` | UI 스타일·색·배치 가이드 | G 메뉴·상점 화면 설계 |
| `emil-design-eng` | 버튼 눌림·애니메이션 같은 세부 품질 | 화면 다듬기 |
| `frontend-design` | 디자인 방향 잡기 | 새 화면 콘셉트 |
| `ponytail` | 최소한의 코드로 고치기 (현재 켜져 있음) | 모든 수정 |
| `ponytail-audit` | 저장소 전체 점검 보고서 | 코드 오류·최적화 점검 |
| `ponytail-review` / `code-review` | 변경 내용 검토 | 커밋 전 검토 |
| `simplify` | 코드 정리 | 중복 제거 |
| `superpowers:systematic-debugging` | 원인부터 찾는 디버깅 순서 | 오류 분석 |
| `superpowers:verification-before-completion` | 끝내기 전 확인 습관 | 업데이트 마무리 |
| `security-review` / `security-audit` | 보안 점검 | 서버 공개 전 |
| `dataviz` | 차트·표 시각화 | 가격·통계 정리 |
| `anthropic-skills:docs` (Claude Docs) | 공유 문서 작성 | 상점 해금표 문서 |

## 이 환경의 제약
- 일부 웹사이트(Bulbapedia, Pixelmon 위키, GitHub gist)는 네트워크에서 막혀 직접 못 엶 → 검색 요약으로 확인.
- 사용자 PC는 연결되어 있지 않음 → PC에서 할 일(서버 실행, playit 설치)은 사용자가 직접.
