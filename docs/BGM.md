# BGM (배경음악)

> **BGM 파일 올리는 곳**: https://github.com/leonwater/cobblemon-server/tree/main/mod/src/main/resources/assets/pokeserver/sounds/bgm
> GitHub에서 **Add file → Upload files** → 맨 아래 **Commit changes**까지 눌러야 올라감. wav·mp3 그대로 올리면 ogg로 바꿔 넣음. 파일 이름은 번호(예: `42.wav`).

## 1. 코블몬 기본 BGM
- **코블몬(1.8.4)에는 기본 BGM이 없음.** 마을·야생·포켓몬 센터 등 공간 음악은 따로 없고, 마인크래프트 기본 음악이 그대로 나옴.
- 코블몬에 있는 것은 **배틀 음악 자리 3개**뿐이고, **셋 다 음악 파일이 비어 있음** (리소스팩으로 채우라고 만들어 둔 자리):

  | 소리 이름 | 언제 | 기본 음악 |
  | --- | --- | --- |
  | `cobblemon:battle.pvw.default` | 야생 포켓몬 배틀 | 없음 (빈 자리) |
  | `cobblemon:battle.pvn.default` | NPC(트레이너·관장) 배틀 | 없음 (빈 자리) |
  | `cobblemon:battle.pvp.default` | 플레이어끼리 배틀 | 없음 (빈 자리) |

- 배틀이 시작되면 코블몬이 위 배틀 음악을 틀고 그동안 마인크래프트 음악을 잠시 멈춤 (`BattleMusicController`, `MusicManagerMixin`). 파일이 비어 있어서 실제로는 아무 소리도 안 남.
- 같이 쓰는 모드(Mega Showdown, 전설 포켓몬 추가 모드 등)에도 긴 음악(BGM)은 없음. 기술·울음소리 같은 효과음만 있음.
- 조사 방법: 각 모드 파일 안의 `sounds.json`과 음악 관련 코드를 직접 열어 확인.

## 2. 잡켓몬 서버 공간 BGM
- **그 공간에 있을 때만** 나옴. 벗어나면 바로 꺼지고 마인크래프트 기본 음악으로 돌아감.
- 소리 크기: 마인크래프트 **설정 → 음악 및 소리 → 음악**으로 조절 (끄면 안 들림).
- 곡이 끝나면 쉬지 않고 처음부터 다시.

| 공간 | 곡 | 정하는 기준 |
| --- | --- | --- |
| 마인크래프트 메인 화면 | 1번 | 서버에 들어가기 전 화면 |
| 광장 | 2번 | 정보창 위치 "광장 마을" (광장 둘레 72칸 안) |
| 포켓몬 센터 | 10번 | 정보창 위치 "포켓몬 센터" (광장의 센터 건물 안) |
| 체육관 | 20번 | 정보창 위치 "체육관" = 체육관 로비만. 관장을 고르면 가는 **경기장·사천왕 본부는 "경기장"이라 안 나옴** |
| 튜토리얼 공간 | 13번 | 정보창 위치 "오박사 연구소" |
| 상점 | 9번 | 정보창 위치 "상점" (광장의 프렌들리 숍 건물 안) |
| 사천왕 본부 | 42번 | 정보창 위치 "사천왕 본부" (배틀 전·후. 배틀 중엔 배틀 BGM) |

- 야생·농장·경기장(1~8번)에서는 공간 BGM 없음 (마인크래프트 기본 음악).

## 3. 배틀 BGM
| 배틀 | 곡 |
| --- | --- |
| 야생 포켓몬 배틀 · 트레이너 배틀 · 플레이어끼리 배틀 · 사천왕 | 7번 |
| 체육관 관장 배틀 (1~8번 경기장) | 28번 |

- 배틀 중에만 나오고 끝나면 꺼짐. 크기는 공간 BGM과 같은 **음악** 볼륨. 배틀 동안 공간 BGM은 잠시 멈췄다가 끝나면 다시 나옴 (코블몬 배틀 음악 기능을 그대로 씀).
- 배틀이 시작될 때 서버가 플레이어 쪽 배틀 곡을 정해 줌 (`CobblemonHooks` 배틀 시작 이벤트, `PlayerBattleActor.battleTheme`). RCT 트레이너(관장 포함) 배틀은 원래 곡이 비어 있어서 여기서 정하지 않으면 아무것도 안 나옴.
- 사천왕은 "체육관 관장 배틀"이 아니라서 7번. 28번으로 바꾸려면 `gymNo` 조건(1~8)을 1~9로.
- 코드: `Bgm.java`(공간 → 곡), `MusicMixin.java`(마인크래프트가 고르는 음악을 바꿈), 서버 `Nicknames.place()`(위치 이름).
- 파일: `mod/src/main/resources/assets/pokeserver/sounds/bgm/bgm_번호.ogg` (서버장이 올린 wav를 ogg 128kbps로 바꿈, 9곡 합쳐 약 14MB). 목록은 `assets/pokeserver/sounds.json`.
- 새 곡을 넣으려면 같은 폴더에 올리고 어느 공간에 쓸지 알려 주면 됨 (README 참고).

## 4. BGM이 비는 곳 (지금은 마인크래프트 기본 음악이거나 다른 곳과 같은 곡)
곡을 올리고 "어디에 몇 번"만 알려 주면 바로 연결됨. 위에서부터 플레이어가 오래 머무는 순서.

| 비는 곳 | 지금 나오는 것 | 비고 |
| --- | --- | --- |
| **야생** (광장 밖) | 마인크래프트 기본 음악 | 가장 오래 있는 곳. 낮·밤, 숲·바다 등 바이옴별로 나눌 수도 있음 |
| **농장** | 마인크래프트 기본 음악 | 농사·건축하며 오래 머무는 곳 |
| **경기장 1~8번** (관장을 고른 뒤 배틀 전·후) | 마인크래프트 기본 음악 | 관장 배틀이 시작되면 28번으로 바뀜. 대기 시간은 짧음 |
| **사천왕 배틀** | 7번 (일반 배틀과 같은 곡) | 전용 곡을 넣거나 28번(관장 배틀)으로 바꿀 수 있음 |
| **전설·환상 포켓몬 배틀** (1시간마다 나타나는 전설 포함) | 7번 | 전용 곡을 넣으면 그 배틀만 바꿀 수 있음 |
| **플레이어끼리 배틀 / 트레이너 배틀** | 7번 (야생 배틀과 같은 곡) | 종류별로 나누고 싶으면 곡을 따로 |
| **명예의 전당** (사천왕을 모두 이긴 뒤) | 42번 (사천왕 본부와 같은 곡) | 클리어 연출용 곡을 넣을 수 있음 |
| **짧은 효과음 (징글)**: 배지 획득·사천왕 클리어·포켓몬 센터 회복 | 없음 | 배경음악이 아닌 몇 초짜리 소리. 넣으려면 따로 작업 |

- 마인크래프트 메인 화면(1번)은 서버에 접속하는 동안(로딩 화면)에도 같이 나옴.
- 튜토리얼 곡(13번)은 37초로 짧아서 금방 다시 처음부터 나옴. 긴 곡으로 바꿔도 됨.
