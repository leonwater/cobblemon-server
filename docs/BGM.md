# BGM (배경음악)

## 1. 코블몬 기본 BGM
- **코블몬(1.8.4)에는 기본 BGM이 없음.** 마을·야생·포켓몬 센터 등 공간 음악은 따로 없고, 마인크래프트 기본 음악이 그대로 나옴.
- 코블몬에 있는 것은 **배틀 음악 자리 3개**뿐이고, **셋 다 음악 파일이 비어 있음** (리소스팩으로 채우라고 만들어 둔 자리):

  | 소리 이름 | 언제 | 기본 음악 |
  | --- | --- | --- |
  | `cobblemon:battle.pvw.default` | 야생 포켓몬 배틀 | 없음 (빈 자리) |
  | `cobblemon:battle.pvn.default` | NPC(트레이너·관장) 배틀 | 없음 (빈 자리) |
  | `cobblemon:battle.pvp.default` | 플레이어끼리 배틀 | 없음 (빈 자리) |

- 배틀이 시작되면 코블몬이 위 배틀 음악을 틀고 그동안 마인크래프트 음악을 잠시 멈춤 (`BattleMusicController`, `MusicManagerMixin`). 파일이 비어 있어서 실제로는 아무 소리도 안 남.
- 같이 쓰는 모드(Mega Showdown, 전설 포켓몬 추가 모드 등)에도 긴 음악(BGM)은 없음. 기술·울음소리 같은 효과음만 있음.
- 조사 방법: 각 모드 파일 안의 `sounds.json`과 음악 관련 코드를 직접 열어 확인.

## 2. 잡켓몬 서버 공간 BGM
- **그 공간에 있을 때만** 나옴. 벗어나면 바로 꺼지고 마인크래프트 기본 음악으로 돌아감.
- 소리 크기: 마인크래프트 **설정 → 음악 및 소리 → 음악**으로 조절 (끄면 안 들림).
- 곡이 끝나면 쉬지 않고 처음부터 다시.

| 공간 | 곡 | 정하는 기준 |
| --- | --- | --- |
| 마인크래프트 메인 화면 | 1번 | 서버에 들어가기 전 화면 |
| 광장 | 2번 | 정보창 위치 "광장 마을" (광장 둘레 72칸 안) |
| 포켓몬 센터 | 10번 | 정보창 위치 "포켓몬 센터" (광장의 센터 건물 안) |
| 체육관 | 20번 | 정보창 위치 "체육관" = 체육관 로비만. 관장을 고르면 가는 **경기장·사천왕 본부는 "경기장"이라 안 나옴** |
| 튜토리얼 공간 | 13번 | 정보창 위치 "오박사 연구소" |

- 야생·농장·경기장에서는 공간 BGM 없음 (마인크래프트 기본 음악).
- 코드: `Bgm.java`(공간 → 곡), `MusicMixin.java`(마인크래프트가 고르는 음악을 바꿈), 서버 `Nicknames.place()`(위치 이름).
- 파일: `mod/src/main/resources/assets/pokeserver/sounds/bgm/bgm_번호.ogg` (서버장이 올린 wav를 ogg 128kbps로 바꿈, 5곡 합쳐 약 6.4MB). 목록은 `assets/pokeserver/sounds.json`.
- 새 곡을 넣으려면 같은 폴더에 올리고 어느 공간에 쓸지 알려 주면 됨 (README 참고).
