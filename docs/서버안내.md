# 서버 안내

Minecraft 1.21.1 Fabric 포켓몬 서버 (Cobblemon). 맵별로 정리.

## 공통
- 포켓몬 외 몬스터·동물 없음. 배고픔 없음.
- 죽어도 아이템 유지. 폭발로 블록이 안 부서짐.
- **G 키**: 메인 메뉴 (왼쪽 분류: 포켓몬·간편 메뉴·워프, 아래 내 정보: 잡은/마주친 포켓몬·잔액·배지).
- 돈: `/money`, 송금 `/pay 닉네임 금액`.
- 명령어는 한국어·영어 둘 다 (`/돈` `/money`, `/가기` `/tpa`, `/부르기` `/tpahere`, `/광장` `/spawn` …).
- 텔레포트: 상대가 [예]를 눌러야 이동, 10초 지나면 취소. OP는 바로 이동.
- **닉네임**: 튜토리얼 마지막 쪽에서 직접 입력. 채팅·머리 위·탭 목록에 보임.
- **칭호** (닉네임 앞): 배지·도감·번 돈·상점에서 쓴 돈·플레이어 배틀 승리·전설 포획·농장 땅으로 18가지. **G 메뉴 → 간편 메뉴 → 칭호**에서 골라 씀.
- **바닥 아이템 정리**: 10분마다 바닥에 떨어진 아이템을 지움 (지우기 30초 전에 채팅 알림). 버린 아이템은 빨리 주우세요.
- 오른쪽 가운데 **정보창**: 닉네임, 위치, 소지금, 배지, 시간, 바이옴, 좌표.
- 미니맵(Xaero), 배틀 화면 확장(상성·속도 범위 표시).
- 명령어 전체: `docs/명령어.md`.
- 초기화 (운영자만): `/초기화` = 서버의 모든 플레이어, `/초기화 닉네임` = 그 사람만.
- **플레이어끼리 때리기**: 블록을 고칠 수 없는 곳(광장 마을·체육관·연구소·남의 농장 땅)에서는 안 됨. 야생(광장 밖)과 내 농장 땅에서만.
- **스타팅 포켓몬**: 레벨 5, 기술은 그 포켓몬이 처음 나온 원작에서 레벨 5까지 배우는 것 (예: 이상해씨 몸통박치기·울음소리).
- **야생 포켓몬**: 광장 가운데에서 108칸 안에는 안 나옴. 렉 방지로 야생에 있는 사람 1명당 30마리까지만.
- **셰이더를 켜 두면** 게임 설정의 구름·그림자 옵션이 적용되지 않음 (셰이더가 따로 그림). 끄려면 **K 키**(셰이더 끄기) 또는 `비디오 설정 → 셰이더 팩 → 셰이더 설정`에서 구름·그림자 끄기.
- 모든 포켓몬 모델 있음 (메가진화·거다이맥스 포함).

## 튜토리얼 — 오박사 연구소
- 첫 접속 장소. 흰 석영 벽의 연구소.
- **오박사** 우클릭 → 사진 11쪽 설명 (도감 사용법, 마지막 쪽 닉네임 입력).
- "준비 완료!" → 보상 → **바로 광장 마을로 이동** → **스타팅 포켓몬** 고르기. 닉네임은 첫 튜토리얼에서만 정할 수 있음.
- 스타팅: 1~9세대 중 무작위 한 세대의 3마리 (피카츄·이브이 없음).
- 첫 물품: 5,000원, 몬스터볼 10개, 러닝 슈즈, 농장 땅 문서 1장, **포켓몬 도감**.
- 튜토리얼 중엔 워프 불가.

## 광장 마을 (야생 안)
- 야생 맵의 첫 스폰 자리(꽃 숲)에 있는 **마을**. 서버를 처음 켤 때 모드가 땅이 넓고 평평한 곳을 골라 짓는다.
- 가운데 **분수 + 몬스터볼 조형물**, 남쪽이 도착·리스폰 지점. 튜토리얼을 끝내면 여기로.
- **포켓몬센터**(동쪽, 문은 분수 쪽): 간호사, 회복 장치, PC. 원작풍 흰 벽·빨간 계단 지붕.
- **프렌들리 숍**(서쪽): 점원 2명 → 상점. 흰 벽·파란 계단 지붕.
- **포켓몬 상식 건물 6채**(각기 다른 모양): 나무 정면 식당풍 2, 청록·이끼 지붕 집 2, **따라큐 모양 건물**, 체육관풍 작은 건물.
- 굽은 흙길(동서남북 출구), 나무·덤불·꽃, 연못, 밭, 바위, 가로등, 벤치.
- 반지름 **72칸**: 블록 수정 금지, 포켓몬 안 나옴. 그 밖 ~ 200칸: **저레벨(≤15)**. 둘레 벽 없음 (걸어서 야생으로).
- `/광장` (`/spawn`) 또는 G 메뉴 "광장"으로 언제든 돌아옴.

## 체육관
- 계단 위 체육관 건물 (흰 벽·파란 창 띠·빨강 흰 기둥·겹친 황토색 지붕·노란 차양) → **안내원** 우클릭 → 도전할 관장 고르기.
- 관장·챔피언은 원작풍 스킨.
- 관장 8명 (한 타입씩), 한 번에 한 명만 도전.
- 이기면 배지 + 상금(레벨 제한×100원) + 레벨 제한 +10.
- 지면(도망 포함) **5분 뒤**에 다시 도전.
- 레벨 제한: 처음 20 → 배지마다 +10 → 사천왕 전 100.
- **사천왕**: 배지 8개 후, 역대 챔피언 4명 연속. 클리어 상금 10,000원.

## 야생
- 끝없는 맵. 포켓몬은 **야생에서만** 나옴.
- 첫 방문은 광장 마을 남쪽. 마을 72칸은 포켓몬 없음, 200칸까지 15레벨 이하.
- 첫 스폰 둘레 지형은 미리 만들어 둬서 렉 없음.
- 마을·폐광·유적·메가 유적 같은 건축물이 있음.
- 전설·환상 포켓몬은 아주 드물게 50~70레벨 (첫 스폰 근처엔 없음).
- **1시간마다** (서버가 켜져 있는 동안) 야생의 무작위 플레이어 근처에 **그 바이옴에 맞는 전설·환상 1마리**. 채팅으로 알림.
- 초보 구역(첫 스폰 근처)엔 안 나옴. 그 시각에 야생에 아무도 없으면 건너뛰고 다음 시각에.
- 내 최고 레벨보다 5레벨 넘게 높으면 포획률이 내려감.
- 야생 배틀·플레이어 배틀은 야생(광장 마을 포함)에서만.

## 농장
- **25칸**의 개인 땅 (5×5). **땅 문서**로 빈 땅을 우클릭해 등록.
- 내 땅만 수정 가능. 땅 문서는 살수록 비싸짐.
- 마지막 위치로 워프. 입구 발판 → 광장.
