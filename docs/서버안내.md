# 서버 안내

잡켓몬 서버는 마인크래프트 1.21.1 + Cobblemon(포켓몬 모드) 서버입니다. 아래는 **바닐라·Cobblemon과 다른 점** 위주로 짧게 정리했습니다.

## 시작하기
1. 처음 들어오면 **오박사 연구소**. 오박사를 우클릭하면 설명 11쪽.
2. 마지막 쪽에서 **닉네임** 입력 (한 번만 정할 수 있음).
3. **스타팅 포켓몬**: 1~9세대 중 무작위 한 세대의 3마리에서 고름 (레벨 5).
4. 첫 물품: 3,000원, 몬스터볼 10개, 러닝 슈즈, 농장 땅 문서 1장, 포켓몬 도감 → **광장 마을**로 이동.

## 조작
| 키·명령어 | 하는 일 |
| --- | --- |
| **G 키** | 메인 메뉴: 파티·PC·도감 / 튜토리얼·칭호·명령어·휴지통 / 워프(야생·농장·체육관) |
| **R · M · ↑↓** | 포켓몬 꺼내기 · 상태창 · 파티 고르기 (Cobblemon) |
| **K 키** | 셰이더 끄기·켜기 (셰이더가 켜져 있으면 구름·그림자 설정이 안 먹음) |
| `/명령어` | 명령어 목록 (자세히는 **명령어** 문서) |

## 바닐라와 다른 점
- **몬스터·동물 없음** (포켓몬만), **배고픔 없음**, **죽어도 아이템 유지**.
- **블록은 야생과 내 농장 땅에서만** 고칠 수 있음. 광장 마을·체육관·연구소는 고정(모험 모드, 문·PC·회복 기계·작업대는 사용 가능).
- 폭발로 블록이 안 부서지고, 불은 번지지 않음.
- 플레이어끼리 공격은 **야생과 내 농장 땅에서만**.
- **돈(원)**: 상점에서 사고팔기, `/송금`. 잔액은 G 메뉴·오른쪽 정보창.
- **오른쪽 정보창의 시간** = 이번 접속 후 플레이한 시간(시:분). **G 메뉴**에는 모은 배지 8칸(못 얻은 배지는 모양만).
- **텔레포트는 요청제**: `/tp 닉네임`(가기)·`/tpa 닉네임`(부르기) → 상대가 **[예]**를 눌러야 이동, 10초 지나면 취소.
- 바닥에 떨어진 아이템은 **10분마다 정리** (30초 전 채팅 알림).
- 오른쪽 위 알림(발전 과제 등)은 안 뜸. 채팅 알림은 그대로.
- **칭호**: 배지·도감·돈·배틀 기록 등으로 18가지. G 메뉴 → 칭호에서 골라 닉네임 앞에 붙임.

## Cobblemon과 다른 점
- **포켓몬은 야생 맵에서만** 나옴. 광장 마을 72칸 안은 없음, 200칸까지는 **15레벨 이하**.
- **레벨 제한**: 처음 20 → 배지마다 +10 (사천왕 앞 95·100). 제한보다 높게는 못 키움 (G 메뉴 왼쪽 위에 표시).
- 내 최고 레벨보다 **5레벨 넘게 높은 포켓몬**은 1레벨당 포획률 -5% (최저 10%).
- **1시간마다** 야생의 무작위 플레이어 근처에 전설·환상 1마리 (채팅 알림).
- 야생·플레이어 배틀은 **야생(광장 포함)에서만**.
- **특수 기믹**: 관장을 이기면 도구를 받고 그때부터 배틀에서 쓸 수 있음.

  | 기믹 | 도구 (받는 때) | 배틀에서 쓸 수 있는 때 |
  | --- | --- | --- |
  | Z기술 | Z링 (2번째 관장) | 제한 없음 (Z링 + Z크리스탈) |
  | 메가진화 | 메가링 (4번째 관장) | 배지 4개부터 |
  | 다이맥스·거다이맥스 | 다이맥스밴드 (6번째 관장) | 배지 6개부터 |
  | 테라스탈 | 테라스탈 오브 (8번째 관장) | 배지 8개부터 |

  도구는 손에 들거나 장신구 칸에 껴야 함. **Z크리스탈**은 야생 포켓몬을 이기면 5% 확률로 (그 포켓몬 타입).

## 광장 마을
- **포켓몬센터**: 간호사(회복), PC.
- **프렌들리 숍**: **포켓몬 상점**(볼·회복·성장·도구·능력치·기믹)과 **생활 상점**(농장·블록·잡화).
  - 포켓몬 물품은 **배지를 모을수록 늘어남** (볼·회복·경험사탕 → 진화·열매·노력치 → 지닌 도구 → 성격·개체값). 기믹 물품은 그 기믹이 풀리는 배지에.
  - 생활 물품은 처음부터. 거의 모든 물품을 팔 수 있음 (구매가의 1/4).
- **포켓몬 상식 건물 6채**: NPC가 개체값·노력치·성격·상성·포획·진화·기술을 짧게 알려 줌.
- `/광장` 또는 G 메뉴 워프 "야생"으로 언제든 돌아옴.

## 체육관·사천왕
- 체육관 건물 **안내원** 우클릭 → **배지 케이스** 화면에서 관장 고르기 (얻은 배지는 그림, 못 얻은 배지는 모양만). 한 관장에 한 명씩, 지면 **5분 뒤** 다시 도전.
- 관장 순서: 웅(바위) → 마티스(전기) → 강연(불꽃) → 독수(독) → 초련(에스퍼) → 비주기(땅) → 민화(풀) → 이슬(물).
- 관장도 기믹을 씀: Z기술 3번째부터, 메가진화 5번째부터, 다이맥스 7번째부터.
- **보상**: 배지 + 상금(레벨 제한×200원) + 경험사탕 5개 + 그 타입 기술머신 + 레벨 제한 +10 (2·4·6·8번째는 기믹 도구도).
- **사천왕** (배지 8개 후): 성호 → 난천 → 단델 → 최종 보스 레드. 4명을 **한 번에** 이겨야 클리어. 보상 30,000원 + 이상한사탕 10개 + 특성패치.

## 농장
- **25칸** 개인 땅. **땅 문서**로 빈 땅을 우클릭해 등록 (문서는 살수록 비쌈).
- 내 땅만 고칠 수 있고, 높이는 땅 아래 5칸 ~ 위 10칸까지.
- 입구 발판 → 광장.
