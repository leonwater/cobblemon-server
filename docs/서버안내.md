# 서버 안내

Minecraft 1.21.1 Fabric 포켓몬 서버 (Cobblemon). 맵별로 정리.

## 공통
- 포켓몬 외 몬스터·동물 없음. 배고픔 없음.
- 죽어도 아이템 유지. 폭발로 블록이 안 부서짐.
- **G 키**: 메인 메뉴 (파티·PC·도감·워프).
- 돈: `/money`, 송금 `/pay 닉네임 금액`.
- 전체 초기화: `/초기화` → `/초기화 확인`.
- 모든 포켓몬 모델 있음 (메가진화·거다이맥스 포함).

## 튜토리얼 — 오박사 연구소
- 첫 접속 장소. 흰 석영 벽의 연구소.
- **오박사** 우클릭 → 사진 9쪽 설명.
- "준비 완료!" → 회의장으로 이동 + **스타팅 포켓몬** 고르기.
- 스타팅: 1~9세대 중 무작위 한 세대의 3마리 (피카츄·이브이 없음).
- 첫 물품: 5,000원, 몬스터볼 10개, 러닝 슈즈, 농장 땅 문서 1장.
- 튜토리얼 중엔 워프 불가.

## 스폰 광장 (회의장)
- 원형 광장, 흰 단상, 남쪽 회의장.
- 둘레 건물 6채: **포켓몬 상식 NPC** (개체값·노력치, 성격·민트, 타입 상성, 포획·레벨 제한, 진화, 기술·도구).
- `/trigger home` 또는 G 메뉴 "광장"으로 언제든 돌아옴.

## 상점가
- **포켓몬센터**: 간호사(회복), 회복 장치, PC.
- **프렌들리 숍**: 안쪽 계산대의 점원 2명 → 상점.
- 상점: 볼 20종, 회복약, 성장 아이템, 성격·노력치, 농장, 작물, 광물, 건축, 도구.
- 배지를 모을수록 상품이 늘어남.

## 체육관
- 계단 위 체육관 건물 → **안내원** 우클릭 → 도전할 관장 고르기.
- 관장 8명 (한 타입씩), 한 번에 한 명만 도전.
- 이기면 배지 + 상금(레벨 제한×100원) + 레벨 제한 +10.
- 레벨 제한: 처음 20 → 배지마다 +10 → 사천왕 전 100.
- **사천왕**: 배지 8개 후, 역대 챔피언 4명 연속. 클리어 상금 10,000원.

## 야생
- 끝없는 맵. 포켓몬은 **야생에서만** 나옴.
- 첫 방문은 모두 같은 자리 (꽃 숲). 근처 200칸은 15레벨 이하.
- 첫 스폰 둘레 지형은 미리 만들어 둬서 렉 없음.
- 마을·폐광·유적·메가 유적 같은 건축물이 있음.
- 전설·환상 포켓몬은 아주 드물게 50~70레벨 (첫 스폰 근처엔 없음).
- 내 최고 레벨보다 5레벨 넘게 높으면 포획률이 내려감.
- 야생 배틀·플레이어 배틀은 야생에서만.

## 농장
- 16칸의 개인 땅. **땅 문서**로 빈 땅을 우클릭해 등록.
- 내 땅만 수정 가능. 땅 문서는 살수록 비싸짐.
- 마지막 위치로 워프. 입구 발판 → 회의장.
