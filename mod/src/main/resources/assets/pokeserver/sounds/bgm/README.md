# BGM 넣는 곳

이 폴더에 배경음악 파일을 올리면 모드에 함께 들어가서, 접속하는 모든 사람의 게임에 같이 깔립니다.

## 파일 형식
- **`.ogg` (Ogg Vorbis)** 만 됩니다. 마인크래프트가 mp3·wav를 못 읽습니다.
  - mp3·wav만 있으면 그대로 올려도 됩니다. 작업할 때 `.ogg`로 바꿔서 넣습니다.
- 파일 이름: **영어 소문자·숫자·`_`만** (예: `plaza_day.ogg`, `gym_battle.ogg`). 한글·띄어쓰기·대문자는 안 됩니다.
- 음질: 128kbps 정도면 충분합니다. 한 곡 3~5MB 이하를 권장합니다 (모드 파일이 커지면 접속하는 사람마다 내려받는 시간이 늘어남).
- 원작 포켓몬 BGM처럼 저작권이 있는 음악은 넣지 않습니다. 직접 만들었거나 무료로 써도 되는 음악만.

## 올린 뒤
- 어느 곳(광장·야생·체육관·배틀 등)에서 어떤 곡을 틀지 알려 주면, 재생 기능을 만들어 연결합니다.
